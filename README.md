# 🥋 About

JiuJitsu Manager is a complete web platform designed to simplify the daily operations of Brazilian Jiu-Jitsu academies.

The system centralizes administrative tasks, student management, attendance tracking and financial control into one intuitive platform.

It was developed with scalability, security and performance in mind using Laravel.

---

# ✨ Features

- 👤 Student Management
- 🥋 Belt & Stripe Progression
- 📅 Attendance Control
- 💳 Monthly Payment Management
- 👨‍🏫 Instructor Management
- 📊 Dashboard with Statistics
- 📈 Reports

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/jiujitsu.git
```

Enter the folder

```bash
cd jiujitsu
```

Install dependencies

```bash
composer install
```

Copy environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Run migrations

```bash
php artisan migrate
```

Start server

```bash
php artisan serve
```
